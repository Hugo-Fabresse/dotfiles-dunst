# dotfiles-dunst

Dunst notification daemon configuration.
Minimal, black, no noise.

---

## Dependencies

```bash
sudo pacman -S dunst
```

---

## Install

```bash
git clone git@github.com:Hugo-Fabresse/dotfiles-dunst.git ~/dotfiles/dunst
mkdir -p ~/.config/dunst
ln -s ~/dotfiles/dunst/dunstrc ~/.config/dunst/dunstrc
```

## Content

dunst/
